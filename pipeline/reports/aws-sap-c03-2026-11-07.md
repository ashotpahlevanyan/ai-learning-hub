## Remaining concerns for a human reviewer

1. **Automated source mapping.** Sources were chosen by keyword rules, not by a person. Every URL is live and official, but a spot check is worthwhile. Many questions carry only one topical doc plus the domain exam-guide page.
2. **New options that were not blind-tested.** These were added after the blind solves:
   - The d1 and d2 fifth options (12 items), from verification
   - The d3 and d5 fifth options (7 items), from assembly
3. **Naming.**
   - d1-l3, d1-q20 and the d1 coverage text still say "Route 53 Resolver inbound/outbound endpoints". The exam guide uses that wording, but the product is now Route 53 VPC Resolver. Lesson d1-l3 mentions both names. The source title uses "Route 53 VPC Resolver".
   - d2-q25 keys both "Security Hub CSPM" and "the new AWS Security Hub". The guide is inconsistent about these names.
4. **Claims from general knowledge, kept but not sourced in research.md:**
   - DynamoDB global tables have a multi-Region strong consistency mode (the d1-f34 fix).
   - GWLB uses GENEVE.
   - CloudFront Functions have no network access and run only on viewer events.
   - Serverless inference has payload and duration limits.
   - DAX is API-compatible with DynamoDB.
   - NAT64 is done by the NAT gateway.
   - Control Tower's three control behaviors.
   - ACM renewal of private certificates.
   - Access Analyzer unused-access finding types and zone-of-trust details.
   - Inspector network-exposure scanning.
   - Data transfer from AWS origins to CloudFront is free.
   - S3 Intelligent-Tiering skips small objects.
   - DLM has no extra charge.
   - Budgets actions can stop EC2 and RDS.
   - Graviton options exist for RDS and ElastiCache.
   - The Global Accelerator anycast and failover behavior used by d4-q22 and d4-f19.
   - The COBOL-to-Java and DataSync source/target details in d4-l1.
   - Whether zonal shift depends on the ALB cross-zone setting (d4-q13).
   - Lambda async invocations retry twice by default.
   - Bedrock CloudWatch metric names.
   - SageMaker Model Monitor's four monitor types.
   - Service Quotas request templates.
   - Account-level CloudWatch Logs subscription policies.
5. **Judgment calls on keyed answers.**
   - d2-q37: CloudTrail organization trails already cannot be stopped from member accounts, so the SCP option's value comes mainly from blocking GuardDuty from being disabled. It is defensible as keyed.
   - d3-q14: the keyed tag-policy answer depends on reading "with enforcement" as enough to meet the requirement.

   - Data Transfer Terminal pricing basis and locations.
   - A Security Hub CSPM deprecation timeline (none found).
   - Control Tower 2025–26 features.
   - Global Accelerator and Route 53 routing details, Aurora Global Database switchover timings, and Database Savings Plans payment options (not re-fetched this run).
